# PWA Icons Placeholder

Os seguintes ícones precisam ser criados:

- `pwa-192x192.png` - 192x192px
- `pwa-512x512.png` - 512x512px
- `apple-touch-icon.png` - 180x180px
- `favicon.ico` - 32x32px

## Design Sugerido

**Tema**: Ícone de campainha (🔔) ou casa inteligente (🏠)

**Cores**: 
- Background: #1e293b (slate-800)
- Icon: #3b82f6 (blue-500)

## Ferramentas Online

1. **Favicon Generator**: https://realfavicongenerator.net/
2. **PWA Icon Generator**: https://www.pwabuilder.com/imageGenerator

## Instruções

1. Crie um ícone 512x512px com o design acima
2. Use uma ferramenta para gerar todos os tamanhos
3. Substitua os arquivos nesta pasta
4. O vite.config.ts já está configurado para usá-los

## Alternativa Rápida (Emoji to PNG)

1. Acesse: https://emoji.gg/
2. Procure por "bell" ou "house"
3. Download do emoji em alta resolução
4. Redimensione para os tamanhos necessários
